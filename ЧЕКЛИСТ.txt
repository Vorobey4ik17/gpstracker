GPS TRACKER - ФИНАЛЬНЫЙ ЧЕКЛИСТ
================================

УЖА СОБРАНО (в этом архиве):
- Сервер + база + карта (server.py, dashboard.html)
- Приложение FastVPN с PIN 6138, гео каждые 10 сек
- Домен вшит во все файлы: https://punctured-detail-expansive.ngrok-free.dev
- START.bat - автозапуск сервера и туннеля

ОСТАЛОСЬ СДЕЛАТЬ ВАМ (3 шага):

ШАГ 1. Запуск системы (за минуту до игры)
  - Распакуйте архив
  - Двойной клик: START.bat
  - Проверка: откройте в браузере https://punctured-detail-expansive.ngrok-free.dev
    -> нажмите "Visit Site" -> должна быть карта мира

ШАГ 2. Сборка приложения (один раз заранее)
  1. Установите Android Studio (developer.android.com/studio)
  2. File -> Open -> папка "android" из этого архива
  3. Подождите синхронизации Gradle (5-15 мин)
  4. Build -> Build Bundle(s)/APK(s) -> Build APK(s)
  5. Внизу справа уведомление "APK(s) generated" -> нажмите "locate"
  6. Файл app-debug.apk - это приложение. Раздайте участникам.

ШАГ 3. На телефоне участника
  1. Установите APK (разрешите "установку из неизвестных источников")
  2. Откройте FastVPN, включите переключатель "VPN"
  3. Выдайте ВСЕ разрешения (геолокация - "всегда", уведомления)
  4. Готово - точка едет на диспетчерской карте

ПРАВИЛА ИГРЫ:
- Участники ищут FastVPN на телефоне
- Переключатель VPN ВЫКЛЮЧАЕТ ТОЛЬКО НАДПИСЬ - трекинг продолжается!
- Реальное отключение: Настройки -> PIN 6138
- После верного PIN приложение можно удалить - жучок нейтрализован

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:
- localhost:5000 не открывается -> сервер не запущен -> START.bat
- ngrok адрес не открывается -> туннель не запущен -> START.bat
- Точка не едет на карте -> на телефоне не выдано разрешение
  "геолокация всегда" или нет интернета


================================
СБОРКА APK ОНЛАЙН (БЕЗ ANDROID STUDIO)
================================
1. Зайдите на github.com -> зарегистрируйтесь (бесплатно)
2. Нажмите "New repository" -> имя: gpstracker -> Public -> Create repository
3. Нажмите "uploading an existing file" -> перетащите ВСЕ файлы
   и папки из архива (gpstracker_local) прямо в окно браузера
   (папка android должна лежать в корне репозитория!)
4. Нажмите "Commit changes"
5. Перейдите во вкладку "Actions" -> слева "Build APK" ->
   справа "Run workflow" -> Run workflow
6. Ждите 10-15 минут (жёлтый кружок = идёт сборка, зелёная галка = готово)
7. Откройте закончившийся запуск -> внизу "Artifacts" ->
   FastVPN-apk -> Download
8. В скачанном zip лежит app-debug.apk - это приложение!

Если сборка упала с ошибкой - пришлите скрин, разберём.
