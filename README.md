# GPS Tracker (локальный вариант) — без облака, без аккаунтов

Всё работает на вашем ноутбуке: сервер + база SQLite + веб-карта.
Телефон шлёт точки на ноутбук по Wi-Fi. Нужен только Python.

## Запуск

1. Установите зависимости (один раз):
   pip install flask flask-socketio

2. Узнайте IP ноутбука в Wi-Fi:
   - Windows: ipconfig  (например 192.168.1.50)
   - Linux/Mac: ifconfig или ip a

3. Запустите сервер:
   python server.py
   Откроется карта: http://localhost:5000

4. Проверка без телефона (второй терминал):
   python simulate.py
   На карте поедет маркер «device-001».

5. Приложение Android:
   - Откройте папку android/ в Android Studio.
   - В LocationService.kt вставьте IP ноутбука в SERVER_URL.
   - Подключите телефон к той же Wi-Fi сети, что и ноутбук.
   - Run -> выдайте разрешения -> «Старт отслеживания».
   - Маркер на карте ноутбука поедет в реальном времени.

## Если телефон не достукивается до ноутбука

- Включите на телефоне мобильную точку доступа и подключите ноутбук к ней
  (в обычном хакатонном Wi-Fi часто включена изоляция клиентов — точка решает это).
- Проверьте, что телефон и ноутбук в одной сети: с телефона откройте
  в браузере http://IP-НОУТБУКА:5000 — должна открыться карта.
- Windows: разрешите Python в брандмауэре при первом запуске.

## Что внутри

- server.py     — Flask + WebSocket + SQLite, раздаёт карту и принимает точки
- dashboard.html — карта диспетчера (Leaflet), live-обновление через WebSocket
- android/      — приложение (foreground service, GPS каждые 3 сек/5 м,
                  пакетная отправка раз в 10 сек, буфер при обрыве сети)
- simulate.py   — генератор фейковых точек для проверки карты

## Для защиты

- Все точки лежат в gps.db (SQLite) — можно показать «железную» базу.
- Геозоны: в server.py есть готовый пример проверки расстояния (функция haversine)
  — можно добавить алерт на карту за 20 строк.
- Экспорт трека: select * from locations — выдать в GPX/CSV.

# Приложение-«жучок» для игры (все участники в курсе)

Приложение выглядит как «Служба подключений» со стандартной иконкой,
стартует само после перезагрузки, уведомление минимально заметное.
Полностью без уведомления сделать нельзя — Android требует его для фонового GPS.

Повышение сложности для игры:
- Раздайте участникам прошивку через свой APK (Build -> Build APK), имя пакета com.secure.netcore
- Можно сменить порт сервера на 443 в server.py и SERVER_URL — трафик похож на HTTPS

## Чек-лист «как найти жучок» (для команды поиска)

1. Настройки -> Приложения -> сортировка/список: свежеустановленные, незнакомые имена
2. Настройки -> Геоданные -> Разрешения приложений -> фильтр «Разрешено всегда»
3. Настройки -> Батарея -> расход: кто жрёт фоном
4. Шторка уведомлений: постоянная служба, которую нельзя смахнуть
5. Настройки -> Безопасность -> Администраторы устройства
6. Настройки -> Специальные возможности (чужие службы accessibility)
7. Роутер/Wi-Fi анализатор: телефон, который стучится на чужой IP:порт каждые N секунд
   (в Wireshark фильтр: tcp.port == 5000)
8. Data usage приложений: незнакомое приложение с регулярным мелким исходящим трафиком

## Механика «жучка» в игре

- Геолокация: точка каждые 10 секунд, отправка на сервер каждые 10 секунд.
- Карта диспетчера: гибрид (спутник + подписи Esri), вид на весь мир, трек обрамляется автоматически.
- Отключение: кнопка «Отключить» в уведомлении и в приложении открывает экран с 4 заданиями.
  Каждое задание даёт одну цифру 4-значного кода. Верный код отключает службу и разрешает удаление.
- После ввода кода служба больше не перезапускается (в т.ч. после перезагрузки телефона).

### Как поменять задания и код

Откройте UnlockActivity.kt, найдите список `tasks` — каждая строка это пара
"вопрос" to "цифра-ответ". Поменяйте тексты и ответы, код соберётся из ответов автоматически.

## Работа через интернет (телефон на мобильной сети)

Общая Wi-Fi сеть больше не нужна. Ноутбук-диспетчер выставляется в интернет через туннель.

### Вариант A: cloudflared (без регистрации)

1. Скачайте: https://github.com/cloudflare/cloudflared/releases
   (файл cloudflared-windows-amd64.msi, установите)
2. В терминале:  cloudflared tunnel --url http://localhost:5000
3. Через секунду появится адрес вида https://xxxx-yyyy.trycloudflare.com
4. Вставьте его в SERVER_URL (LocationService.kt) и соберите APK.
   Минус: адрес меняется при каждом перезапуске туннеля.

### Вариант B: ngrok (стабильный адрес)

1. Регистрация на ngrok.com (бесплатно), скачать ngrok для Windows
2. ngrok config add-authtoken ВАШ_ТОКЕН
3. ngrok http --url=ВАШ_ПОДДОМЕН.ngrok-free.app 5000
   Поддомен закрепляется за вами — адрес не меняется между перезапусками.
4. Адрес https://ВАШ_ПОДДОМЕН.ngrok-free.app -> SERVER_URL.

### Схема

Телефон (LTE/Wi-Fi любой) -> туннель (HTTPS) -> ноутбук: server.py -> карта http://localhost:5000

Трафик минимальный: точка ~150 байт каждые 10 сек (~50 КБ/час).

## Маскировка под VPN

- Приложение называется FastVPN, иконка — замок
- Экран: переключатель «VPN». ВКЛ запускает трекинг. ВЫКЛ меняет только надпись —
  трекинг продолжается (главная ловушка для участников)
- Постоянное уведомление: «FastVPN — Защищённое соединение активно»
- Настоящее отключение: Настройки -> PIN-код 6138
- После верного PIN служба не перезапускается (в т.ч. после перезагрузки)

### Как участники могут вычислить жучок (подсказка для жюри)

- FastVPN просит геолокацию «всегда» — VPN ей не нужен, подозрительно
- Выключили VPN, а на карте диспетчера точка продолжает двигаться
- Настройки -> Батарея: FastVPN жрёт фоном
- Расход мобильного трафика у FastVPN регулярный, каждые 10 сек
